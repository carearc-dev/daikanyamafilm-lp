# DAIKANYAMA FILM LP

縦型ショートドラマ制作サービスのレスポンシブLPです。HTML / CSS / JavaScriptのみで動作し、GitHub Pagesで公開できます。

## ローカルで見る

`index.html` をブラウザーで開いてください。Google Fontsを利用するため、フォント読み込みにはインターネット接続が必要です。

## GitHub Pagesで公開する

このフォルダーの中身をGitHubリポジトリのルートへ配置し、GitHubの **Settings → Pages** で公開元ブランチとルートフォルダーを選択してください。

## ファイル構成

```text
index.html
style.css
script.js
img/
  brand-logo-white.png
  film-set.png
  strengths-set.png
  works-smartphones.png
```

画像の差し替えは `img/` 内で行えます。ファイル名を変える場合は `index.html` の参照先も更新してください。

## 内容について

今回の復元は、会話で確定したデザイン・構成・文言と、残っていた添付画像をもとに再構築しています。削除された元プロジェクトのソースが残っていなかったため、旧サイトと完全に同一のコードではありません。
